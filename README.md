# homebrew-tools

Homebrew formulas for Huli developer tools.

## Usage

```bash
brew install hulilabs/tools/huli-cli
```

The installed binary is named `huli`.

Equivalently, in two steps:

```bash
brew tap hulilabs/tools
brew install huli-cli
```

## Available formulas

- **huli-cli** — the command-line client for the Huli Public FHIR R4 + R5 API.
  Docs: https://developers.huli.ai/v1/cli/

Formulas in this tap are generated automatically on release and should not be
edited by hand.
